- **select / insert / update / delete** — scoped to `company_id`; insert force-sets tenant; update strips `company_id` (can't move rows across tenants even past casts).

## 6. Technical report

### Architecture

Monorepo (pnpm + Turbo): **apps/**{api (Fastify+better-auth+Drizzle/pg16), web (React18+Vite+TanStack), mobile (Flutter/Dart)} · **packages/**{db · contracts (openapi.yaml = single contract) · tokens · i18n · tax-engine · bank-file · notifications} · **tests/ · infra/** (docker-compose: pg16+redis+api+web+worker).
**Engineering rules:** OpenAPI = single contract (FE/mobile gen client, no hand models) · every mutation → AuditLog · `currency_code` on every money column · timestamps UTC · promote feature→dev(auto)→main(Wei) · Done = 5 gates · sacred files enforced by `.claude/hooks/protect-files.sh`.

### Security (STRIDE+OWASP · original: 1 Critical · 4 High)

- **[FIXED] F1 Critical** — role.perms 11×5 matrix never read to gate CRUD → any member `PUT /roles/:id` self-escalate approvalLevel=4 → financial-authz bypass. orch-A fixed (perms gate /users + /roles, exploit-test proven). F2 (audit actor), F3 (prod quota caps), F4 (login throttle) landed.
- **[CONFIRMED] B-084 exploit-closure** — independent end-to-end verify: low-tier cut 7.36M PO = 403 at first mutation · negative-floor 400 · amend-pending 409. Money-path E2E now a regression guard.
- **[SAFE] tenant isolation fail-closed** — TenantDb single write choke point (force company_id, strip smuggled) · IDOR clean (foreign :id→404) · approval endpoints enforce role.approvalLevel.
- **[OPEN] B-084 carry-forward** — F1 fix covered only users/roles CRUD; 27 FLOW-A mutations = 8 ungated / 12 status-only. `b084-fix-spec.md` ready (3 options A/B/C, routes-only) awaiting Wei.
- **[OWED] F5/B-055** — prod compose passes `AUTH_SECRET` but code reads `BETTER_AUTH_SECRET` → prod won't boot (devops). **F6** — password-reset / invited-user activation path never implemented.
